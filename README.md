# rock-paper-scissors-top

This project is the first project in the "JavaScript Basics" module in the "Foundations" course of The Odin Project (TOP).

This project will be revisited later in the curriculum (what I will call "Phase Two" of this project), and that will incorporate programming a GUI. This Phase One of this project's user-interactivity includes only a prompt, with an alert response (and console logging).

This was the first point in the module where we got to create our own JavaScript code, and it was a bit overwhelming. But also *incredibly* rewarding.

Before starting this project, I wasn't sure if I was really understanding all these JavaScript concepts introduced so far, but actually being able to put it all together into a program that can *actually be played* just makes me so proud of myself!

I am finding JavaScript overall to be harder and more abstract than HTML and CSS were at the start, and I am enjoying this new kind of challenge!

I am excited to continue further into the curriculum and learning more JavaScript, and doing the next projects!
